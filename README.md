# Stock Account Management

## Overview

This project is a simple Java application developed as part of the BridgeLabz Internship program.

It demonstrates Object-Oriented Programming concepts by implementing a Stock Account Management System.

## Features

- Add and manage stocks
- Calculate individual stock value
- Calculate total portfolio value
- Buy and sell company shares
- Account debit operation with balance validation
- Display stock portfolio report
