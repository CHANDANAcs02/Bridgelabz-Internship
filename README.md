# Collection Practice (Java)

This repository contains Java programs demonstrating the implementation and usage of the Java Collections Framework. The programs cover commonly used collection classes, interfaces, and operations for efficient data storage and manipulation.

---

## Topics Covered

### List
- ArrayList
- LinkedList
- Vector
- Stack

Operations:
- Add Elements
- Remove Elements
- Update Elements
- Search Elements
- Iterate through Collections
- Sorting Lists

---

### Set
- HashSet
- LinkedHashSet
- TreeSet

Operations:
- Add Elements
- Remove Elements
- Search Elements
- Eliminate Duplicate Values
- Sorted Set Operations

---

### Queue
- PriorityQueue
- Queue Interface

Operations:
- Enqueue
- Dequeue
- Peek
- Poll
- Priority-based Ordering

---

### Map
- HashMap
- LinkedHashMap
- TreeMap

Operations:
- Insert Key-Value Pairs
- Update Values
- Remove Entries
- Search by Key
- Iterate through Map Entries

Implemented custom sorting using:
